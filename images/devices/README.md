# images/devices/

Изображения смартфонов для виджетов покупки в статье
`articles/flagships-2026-old-vs-new.html` (класс `.device-thumb`).

## Как добавить

Положите файл `<slug>.webp` (рекомендуется ~600×780, прозрачный или
светлый фон, устройство по центру). Он подхватится автоматически —
до этого показывается `_placeholder.svg` (через `onerror` у `<img>`).

Формат пути: `../images/devices/<slug>.webp`
